What's inside

Functions

Both plans run on the same core. Here is what each part does for you.

Admin function

See every account that has signed up and when it was created, and manage them from one place.

Server verify

Your program sends a code to the server. The server checks it and replies with valid or invalid, plus the owner's username.

Secure accounts

Passwords are stored as hashes, never as plain text, and new accounts must pass a reCAPTCHA check.

Own database

All user data is kept in a database on your server, so it is simple to back up and move.

Download hub

Logged-in users open the download page and get PTS ver 1 (C) and PTS ver 2 (Python) from GitHub.

And more

New functions are added over time. Ask us about custom features for your server.
